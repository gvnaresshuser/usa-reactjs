## Which should you teach your students?

For your React, Node.js, Express and PostgreSQL full-stack training, I would recommend this sequence:

| Tool           | Teaching purpose                                            |
| -------------- | ----------------------------------------------------------- |
| Thunder Client | Test Express endpoints inside VS Code                       |
| Postman        | Collections, environments, JWT authentication and API tests |
| REST Client    | Execute requests from `.http` files stored with the project |
| Swagger UI     | Document and explore APIs                                   |
| cURL           | Understand HTTP requests from the terminal                  |
| k6             | Introduce load and performance testing                      |

My recommendation: Continue with Thunder Client for everyday endpoint testing, then introduce REST Client and Swagger UI. They provide two different approaches that students can use directly within their development workflow.
