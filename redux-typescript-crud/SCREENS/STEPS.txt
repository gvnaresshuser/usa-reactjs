The main TypeScript additions

| JavaScript              | TypeScript                            |
| ----------------------- | ------------------------------------- |
| `user`                  | `user: User`                          |
| `id`                    | `id: number`                          |
| `users: []`             | `users: User[]`                       |
| `error: null`           | `error: string \| null`               |
| `useState(null)`        | `useState<number \| null>(null)`      |
| `createAsyncThunk(...)` | Typed `createAsyncThunk<...>`         |
| untyped `dispatch`      | `AppDispatch`                         |
| untyped `useSelector`   | `RootState`                           |
| `e`                     | `React.ChangeEvent<HTMLInputElement>` |
| `e` submit              | `React.FormEvent<HTMLFormElement>`    |

One particularly important production principle

Keep these three things separate:

types/
   ↓
"What does my data look like?"

features/
   ↓
"How does my application manage that data?"

components/
   ↓
"How do I display and interact with that data?"

         ↓
    Data definitions

    usersSlice.ts
         ↓
    Redux + API + CRUD

    users/
         ↓
    UI components

App.tsx
    ↓
    Connect everything together
