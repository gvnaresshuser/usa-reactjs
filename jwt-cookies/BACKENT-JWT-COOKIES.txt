Refresh Token Hash Utility
We need a secure one-way hash for the refresh token.
Open:
backend/src/utils/password.ts

Do not replace the existing bcrypt functions.
Add this import at the top:
import crypto from "node:crypto";

Then add this function at the bottom:
export const hashRefreshToken = (
  token: string,
): string => {
  return crypto
    .createHash("sha256")
    .update(token)
    .digest("hex");
};

So the file will contain both:
bcrypt
  ↓
Password hashing

SHA-256
  ↓
Refresh-token hashing

Why not bcrypt for the refresh token?
The refresh token is already a high-entropy random JWT.
For database lookup we want:
same token
   ↓
same SHA-256 hash
   ↓
fast database lookup

This is different from password storage, where bcrypt's deliberately slow hashing is desirable.
