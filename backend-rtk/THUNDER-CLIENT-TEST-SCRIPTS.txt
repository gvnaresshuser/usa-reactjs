## 2. Get All Users — GET
Method: `GET`
URL:
```text
http://localhost:5000/api/users
```
No body required.
### Expected response
You should receive an array of users from JSONPlaceholder:
```json
[
  {
    "id": 1,
    "name": "Leanne Graham",
    "username": "Bret",
    "email": "Sincere@april.biz"
  }
]
```
There will be multiple users.
### Flow
```text
Thunder Client
     ↓
GET /api/users
     ↓
Express
     ↓
fetch(API_URL)
     ↓
JSONPlaceholder
     ↓
users
     ↓
res.json(users)
     ↓
Thunder Client
```

# 3. Add User — POST
Method: `POST`
URL:
```text
http://localhost:5000/api/users
```
Go to:
Body → JSON
Enter:
```json
{
  "name": "Uzwall",
  "username": "uzwall",
  "email": "uzwall@gmail.com"
}
```
Also make sure the request has:
```text
Content-Type: application/json
```
Your middleware:
```js
app.use(express.json());
```
converts the incoming JSON into:
```js
req.body
```
So:
```js
body: JSON.stringify(req.body)
```
sends that data to JSONPlaceholder.
### Expected response
Something similar to:
```json
{
  "name": "Uzwall",
  "username": "uzwall",
  "email": "uzwall@gmail.com",
  "id": 11
}
```
Important: JSONPlaceholder is a fake REST API. The new user is simulated and is not permanently stored.

# 4. Update User — PUT
Method: `PUT`
URL:
```text
http://localhost:5000/api/users/1
```
Here:
```text
:id = 1
```
So Express matches:
```js
app.put("/api/users/:id", ...)
```
### Body → JSON
```json
{
  "name": "Updated Uzwall",
  "username": "updated_uzwall",
  "email": "updated@gmail.com"
}
```
### Expected response
```json
{
  "name": "Updated Uzwall",
  "username": "updated_uzwall",
  "email": "updated@gmail.com",
  "id": 1
}
```
The important part here is:

```js
const { id } = req.params;
```
For:
```text
/api/users/1
```
we get:
```js
id = "1"
```
and then:
```js
fetch(`${API_URL}/${id}`, ...)
```
becomes:
```text
https://jsonplaceholder.typicode.com/users/1
```

### The complete CRUD flow

```text
GET       → Read users
POST      → Create user
PUT       → Update user
DELETE    → Delete user
```

One important teaching point in your example: your Express server is acting as a middle layer/proxy.

```text
Thunder Client / React
          ↓
   Express :5000
          ↓
 JSONPlaceholder API
          ↓
      Response
          ↓
   Express :5000
          ↓
 Thunder Client / React
```

This is a very good example to demonstrate Express + middleware + REST APIs + async/await + external API integration.
