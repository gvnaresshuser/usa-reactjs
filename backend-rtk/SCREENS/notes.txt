======================================================================================
nodemon is a development tool. It watches your files and automatically restarts the Node.js server whenever you make changes.

Install it with:

npm install --save-dev nodemon

or:

npm i -D nodemon

Your package.json will contain:

{
  "devDependencies": {
    "nodemon": "^3.x.x"
  }
}
Typical setup
{
  "scripts": {
    "start": "node src/server.js",
    "dev": "nodemon src/server.js"
  }
}

Then:

npm run dev

During development:

You modify server.js
       ↓
nodemon detects change
       ↓
Server automatically restarts

For production:

npm start

which simply runs:

node src/server.js
One important point

You do not need to install nodemon globally.

Avoid:

npm install -g nodemon

Prefer the project-local installation:

npm i -D nodemon

This keeps the project's tooling and versions controlled by package.json and package-lock.json.

So the rule of thumb is:

express → dependencies
nodemon → devDependencies ✅
