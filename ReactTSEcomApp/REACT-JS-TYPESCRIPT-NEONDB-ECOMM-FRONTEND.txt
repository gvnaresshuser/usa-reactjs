🔐 Important: What happens to the JWT?

This is an important teaching point.

The backend does:

Login
  ↓
Verify email/password
  ↓
Create JWT
  ↓
Set HttpOnly Cookie

The browser stores the cookie.

React doesn't do this:

localStorage.setItem("token", token);

That's intentional.

Our Axios instance already has:

withCredentials: true

so the browser can send the cookie with API requests.

React
  │
  │ POST /api/auth/login
  ▼
Express
  │
  ├── Verify user
  ├── Create JWT
  └── Set HttpOnly Cookie
             │
             ▼
          Browser
             │
             │ automatically sends cookie
             ▼
     Protected API requests

This is exactly the authentication architecture we want to teach.
