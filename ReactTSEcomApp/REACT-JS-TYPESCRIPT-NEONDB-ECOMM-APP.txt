7. Localhost vs Production

This part of our configuration is particularly important.

Local development
secure: false
sameSite: "lax"

because we're using:

http://localhost
Production
secure: true
sameSite: "none"

because our frontend and backend may be on different domains.

Our code handles this automatically:

secure:
    env.nodeEnv === "production",

sameSite:
    env.nodeEnv === "production"
        ? "none"
        : "lax",

So we don't have to keep changing the code when deploying.
